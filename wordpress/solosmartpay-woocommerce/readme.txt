Accept QRIS, Virtual Account, e-wallet, and retail payments in WooCommerce through Solosmartpay.

== Description ==

Customers pay on the Solosmartpay payment page and choose QRIS, bank Virtual Account, e-wallet, or a retail outlet. WooCommerce marks the order paid from a signed webhook. Works with the classic checkout and the Checkout block. Currency must be IDR.

== Installation ==

1. Upload the plugin and activate it.
2. WooCommerce → Settings → Payments → Solosmartpay: enter the API token and webhook secret from the Solosmartpay Developer Hub.
3. Register the webhook URL shown on the settings page in the Developer Hub.
